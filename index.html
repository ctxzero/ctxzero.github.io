          CVE-2026-106933
          Medium, 6.8
          No fix available
          Verified by WPScan
        


        
Blaze Demo Importer ≤ 1.0.16

        
Stored cross-site scripting through SVG upload, reachable from the Author role.


        

          

            
The WordPress plugin registers the SVG MIME type for the media library unconditionally and never sanitises uploaded SVG files. Any account with the Author role or higher can upload a crafted SVG that runs JavaScript in the browser of whoever opens the file, including administrators.

What I test

      
Grouped the way an engagement runs. Every item is something I've used against a real target, not a line from a syllabus.

    

    

      

        
        
SQL injectionUnion, boolean, time-based and out-of-band. Found by hand, automated only to speed up extraction.
Cross-site scriptingReflected, stored and DOM-based, carried through to a real impact demo, not an alert box.
File uploadExtension, content-type and parser bypasses that end in code execution or stored XSS.
SSRFInternal service reach, cloud metadata and protocol smuggling out of one trusted fetch.
IDOR and BOLAObject and function level access control tested across every role the app defines.
Auth bypassSession handling, JWT flaws, reset logic and multi-step flows that trust the wrong step.
SSTITemplate engine detection, then escalation from expression evaluation to RCE.
Command injectionArgument and metacharacter injection, including blind and filtered variants.
LFI and traversalTraversal into source disclosure, log poisoning and file-read-to-RCE chains.
Prototype pollutionPolluting Object.prototype to reach a gadget the application never meant to expose, client and server side.
PHP object injectionUnserialize on attacker-controlled input, then a POP chain through the app's own classes to RCE.
And moreDeserialisation beyond PHP, CORS and cache poisoning, request smuggling, XXE, race conditions, business-logic abuse.

      

      

        
        
BloodHoundGraph the domain and find the shortest honest path from foothold to Domain Admin.
KerberoastingPulling service tickets for SPN accounts and cracking them offline, no noise on the wire.
AS-REP roastingHarvesting hashes from accounts that never required Kerberos pre-authentication.
NTLM relayCoercing authentication and relaying it to a service that forgot to require signing.
ADCS abuseCertificate template misconfiguration, ESC1 through ESC8, into domain-wide authentication.
DCSyncReplicating the directory to pull every hash in the domain once the rights are there.
Delegation abuseUnconstrained, constrained and resource-based delegation turned into impersonation.
ACL abuseGenericAll, WriteDACL and friends: the ACL edges nobody audits after a migration.
And moreSilver and golden tickets, shadow credentials, GPO abuse, LAPS and gMSA reads, trust and cross-forest paths.

PivotingTurning one compromised host into a route to the segments that actually matter.
TunnelingChisel, ligolo and SSH tunnels to reach internal services from outside the perimeter.
Lateral movementReusing credentials and trust relationships to move sideways without tripping anything.
Linux privescSUID, capabilities, cron, kernel and misconfigured services on the way to root.
Windows privescToken abuse, unquoted paths, service permissions and privilege escalation to SYSTEM.
Password attacksSpraying, targeted cracking and credential reuse, quietly and within lockout policy.
And moreSNMP and NFS, LDAP and MSSQL, printer and IoT footholds, VPN and RDP exposure, port forwarding through jump hosts.
